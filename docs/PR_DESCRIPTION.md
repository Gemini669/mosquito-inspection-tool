# 实现中文督导问题与整改建议报告应用

仓库原先仅包含项目简介和 Excel 清单，现提供可直接运行的中文静态网页应用。使用“问题建议库”的全部 138 条记录、17 个原字段，支持按关键词、工作领域及后果类别筛选、多个问题与多个点位记录、本地草稿和 `.docx` 报告导出。

同一后果类别内仅对完全相同的后果原文去重，不同表述完整保留，并标注关联现场记录。每条记录独立列出问题、点位、现场描述、整改建议、责任方、复核点、时效与依据。现场记录及报告均在浏览器内处理，无外部上传、付费 API 或生成式 AI。

原有 README 和 Excel 保持不变。增加 Python 标准库导入器、源文件 SHA-256 与逐字段校验、中文使用说明、锁定依赖、响应式页面和 GitHub Actions 检查。Word 导出延迟加载，不影响首屏资源。

## 验证

- `npm ci`：使用锁文件安装依赖。
- `npm run check`：源数据一致性、9 项数据/业务/Word 测试、生产构建、12 项 Chromium 桌面与手机视口端到端测试。
- 测试逐项确认全部 138 条问题、不同后果和建议未遗漏；解包真实 Word 文件检查所有段落与预览一致；覆盖多点位、刷新恢复、备份/导入、损坏草稿保护、存储失败、复制降级、输入转义和无外部请求。
- 原生 macOS Safari、真实手机及 Microsoft Word/WPS 打开效果尚需人工验收；手机自动化是 Chromium 触屏与视口仿真。

## 使用

见根目录 `USAGE.md`。运行 `npm ci && npm run dev` 开发，`npm run build` 生成可静态部署的 `dist/`。不需要配置密钥或后端。
